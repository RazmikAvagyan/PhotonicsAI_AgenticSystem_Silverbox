[Scientist]: ### 1. Differential Equation of the System

The Silverbox benchmark behaves as a second-order nonlinear oscillator with cubic stiffness (Duffing-type nonlinearity), governed by:

$$y''(t) + a\,y'(t) + b\,y(t) + c\,y(t)^3 = g\,u(t)$$

where $u(t)$ is the electrical input voltage, $y(t)$ is the displacement/output voltage, and $a, b, c, g$ are system parameters representing damping, linear stiffness, cubic nonlinearity, and input gain, respectively.

---

### 2. Neural Network Architecture

Instead of fixing the parametric form of the non-linear restoring force and damping, we use a fully connected neural network $\alpha_\theta$ to parameterize the state-dependent acceleration:

$$\alpha_\theta : \mathbb{R}^3 \to \mathbb{R}, \quad (\tilde{y}, \tilde{v}, \tilde{u}) \mapsto \tilde{a}$$

- **Inputs (3 dimensions):** Normalized position $\tilde{y}$, normalized velocity $\tilde{v}$, and normalized external input $\tilde{u}$.
- **Hidden Layers:** A Multi-Layer Perceptron (MLP) with 2 hidden layers (e.g., 64 units each) and smooth activation functions such as $\tanh$ or GELU to ensure continuous differentiability for ODE integration.
- **Output (1 dimension):** Normalized acceleration $\tilde{a}$.

---

### 3. State Equations and Numerical Scaling

In physical units (volts and seconds), the displacement is small ($y \sim 0.05\text{ V}$), velocity is moderate ($v \sim 20\text{ V/s}$), and acceleration is very large ($a \sim 10^4\text{ V/s}^2$). Direct training on raw values leads to numerical instability and gradient degradation.

To normalize all state variables and derivatives to order $\mathcal{O}(1)$:
1. Compute the scaling factors strictly from the training excerpt ($N = 3072$ samples):
   - $Y_S = \text{std}(y_{\text{train}})$
   - $U_S = \text{std}(u_{\text{train}})$
   - Initial velocity via central/forward finite differences: $v_k = \frac{y_{k+1} - y_k}{\Delta t}$.
   - Characteristic angular frequency scale: $W_0 = \frac{\text{std}(v_{\text{train}})}{Y_S}$.
2. Define dimensionless state variables:
   $$\tilde{y} = \frac{y}{Y_S}, \quad \tilde{u} = \frac{u}{U_S}, \quad \tilde{v} = \frac{v}{W_0 Y_S}, \quad \tau = W_0 t$$
3. The scaled state equations become:
   $$\frac{d\tilde{y}}{d\tau} = \tilde{v}$$
   $$\frac{d\tilde{v}}{d\tau} = \alpha_\theta(\tilde{y}, \tilde{v}, \tilde{u})$$
   with integration step size $H = W_0 \Delta t$, where $\Delta t = 1 / f_s$.

---

### 4. RK4 Integration Scheme

Let the state at step $k$ in scaled coordinates be $\mathbf{x}_k = [\tilde{y}_k, \tilde{v}_k]^T$, and let the input be $\tilde{u}_k$. To step from $\tau_k$ to $\tau_k + H$:

$$f(\mathbf{x}, \tilde{u}) = \begin{bmatrix} \tilde{v} \\ \alpha_\theta(\tilde{y}, \tilde{v}, \tilde{u}) \end{bmatrix}$$

Using the 4th-order Runge-Kutta (RK4) update:
$$\mathbf{k}_1 = f(\mathbf{x}_k, \tilde{u}_k)$$
$$\mathbf{k}_2 = f\left(\mathbf{x}_k + \frac{H}{2}\mathbf{k}_1, \frac{\tilde{u}_k + \tilde{u}_{k+1}}{2}\right)$$
$$\mathbf{k}_3 = f\left(\mathbf{x}_k + \frac{H}{2}\mathbf{k}_2, \frac{\tilde{u}_k + \tilde{u}_{k+1}}{2}\right)$$
$$\mathbf{k}_4 = f(\mathbf{x}_k + H\mathbf{k}_3, \tilde{u}_{k+1})$$
$$\mathbf{x}_{k+1} = \mathbf{x}_k + \frac{H}{6}\left(\mathbf{k}_1 + 2\mathbf{k}_2 + 2\mathbf{k}_3 + \mathbf{k}_4\right)$$

---

### 5. Training Strategy

- **Windowing / Subsequences:** Full-sequence backpropagation over 3072 steps causes exploding/vanishing gradients and slow runtimes. Partition the training sequence into short overlapping or non-overlapping windows of length $L \approx 20$ to $30$ steps.
- **Initial State per Window:** For each window, initialize $\tilde{y}_0$ from the measured $y$ and $\tilde{v}_0$ from finite differences.
- **Loss Function:** Mean Squared Error (MSE) on predicted normalized position over the window:
  $$\mathcal{L}(\theta) = \frac{1}{B \cdot L} \sum_{b=1}^B \sum_{k=1}^L \left(\tilde{y}_{b, k}^{\text{pred}} - \tilde{y}_{b, k}^{\text{meas}}\right)^2$$
- **Optimization:** Adam optimizer with an initial learning rate of $10^{-3}$, cosine or step decay.
- **Budget / Time limit:** Train for approximately 50–60 epochs, setting an elapsed-time cutoff of approximately 3 minutes to guarantee total execution finishes well within the 5-minute CPU constraint.

---

### 6. Free-Run Prediction and Evaluation

- **Evaluation Protocol:**
  - Start at sample index 0 of the excerpt with initial condition:
    $$y_0 = y[0], \quad v_0 = \frac{y[1] - y[0]}{\Delta t}$$
    converted to scaled values $\tilde{y}_0, \tilde{v}_0$.
  - Free-run rollout: Integrate the state across the entire excerpt ($3072 + 1024 = 4096$ steps) using RK4, feeding only the input sequence $u(t)$. At no point during rollout are measured $y$ values used to correct the state.
  - Denormalize the simulated trajectory back to volts:
    $$y^{\text{pred}}(t) = \tilde{y}(t) \cdot Y_S$$
- **Metrics:**
  Compute Root Mean Squared Error (RMSE) in volts:
  - Train RMSE: Over indices $0 \dots 3071$.
  - Test RMSE: Over indices $3072 \dots 4095$.
