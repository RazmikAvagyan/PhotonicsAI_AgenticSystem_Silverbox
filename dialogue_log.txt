[Scientist]: ### 1. Differential Equation and State-Space Formulation

The Silverbox circuit behaves as a forced nonlinear Duffing oscillator governed by the second-order ordinary differential equation:
$$y''(t) + a\,y'(t) + b\,y(t) + c\,y(t)^3 = g\,u(t)$$

Introducing the velocity state $v(t) = y'(t)$, the system can be expressed as a first-order state-space system:
$$\begin{aligned}
\frac{dy}{dt} &= v \\
\frac{dv}{dt} &= \alpha(y, v, u)
\end{aligned}$$
where the physical acceleration $\alpha(y, v, u) = g\,u - a\,v - b\,y - c\,y^3$ is approximated by a parameterised neural network $\alpha_\theta(y, v, u)$ without assuming a priori polynomial terms or explicit coefficient values.

---

### 2. Dimensionless Rescaling and Scaled State Equations

In physical SI units (volts and seconds), the quantities span vastly different magnitudes: output $y \sim 10^{-2}\text{ V}$, velocity $v \sim 10^1\text{ V/s}$, and acceleration $\alpha \sim 10^4\text{ V/s}^2$. Training a neural network directly on these unscaled quantities leads to gradient vanishing/explosion and integration collapse. 

To bring all quantities and derivatives to order $\mathcal{O}(1)$:
1. Compute scale factors from the training portion only:
   - $Y_S = \text{std}(y_{\text{train}})$
   - $U_S = \text{std}(u_{\text{train}})$
   - Approximate velocity on training data: $v_k = \frac{y_{k+1} - y_k}{\Delta t}$, and compute $V_S = \text{std}(v_{\text{train}})$.
   - Characteristic angular frequency scale: $\omega_0 = \frac{V_S}{Y_S}$.
2. Define dimensionless state variables and dimensionless time $\tau$:
   - $\tilde{y} = \frac{y}{Y_S}$
   - $\tilde{u} = \frac{u}{U_S}$
   - Scaled time: $\tau = \omega_0 t$, which implies $d\tau = \omega_0\,dt$ and integration step $h = \omega_0\,\Delta t$.
   - Scaled velocity: $\tilde{v} = \frac{d\tilde{y}}{d\tau} = \frac{1}{\omega_0 Y_S}\frac{dy}{dt} = \frac{v}{V_S}$.

Under this transformation, the state equations integrated by RK4 are:
$$\begin{aligned}
\frac{d\tilde{y}}{d\tau} &= \tilde{v} \\
\frac{d\tilde{v}}{d\tau} &= \tilde{\alpha}_\theta(\tilde{y}, \tilde{v}, \tilde{u})
\end{aligned}$$
Here, $\tilde{y}$, $\tilde{v}$, and $\tilde{u}$ are all zero-mean with unit standard deviation, and the network output $\tilde{\alpha}_\theta$ is $\mathcal{O}(1)$.

---

### 3. Neural Network Architecture

The neural network models the scaled acceleration function $\tilde{\alpha}_\theta: \mathbb{R}^3 \to \mathbb{R}$:
- **Inputs (3 dimensions):** $(\tilde{y}, \tilde{v}, \tilde{u})$.
- **Hidden Layers:** A Multilayer Perceptron (MLP) with 2 hidden layers:
  - Linear layer: $3 \to 64$
  - Activation: $\tanh$ (or GELU / SiLU; smooth activations are preferable for ODE dynamics)
  - Linear layer: $64 \to 64$
  - Activation: $\tanh$
- **Output Layer:** Linear layer: $64 \to 1$ predicting $\frac{d\tilde{v}}{d\tau}$.
- **Initialisation:** Xavier / Glorot uniform initialization to ensure small initial acceleration outputs and stable early integration.

---

### 4. Fourth-Order Runge-Kutta (RK4) Scheme

Given state $\mathbf{x} = [\tilde{y}, \tilde{v}]^T$ and step $h = \omega_0\,\Delta t$:
At step $k$ with input $\tilde{u}_k$, approximating intermediate input values via linear interpolation $\tilde{u}_{k+1/2} = \frac{1}{2}(\tilde{u}_k + \tilde{u}_{k+1})$:
1. $\mathbf{k}_1 = \mathbf{f}(\mathbf{x}_k, \tilde{u}_k) = \begin{bmatrix} \tilde{v}_k \\ \tilde{\alpha}_\theta(\tilde{y}_k, \tilde{v}_k, \tilde{u}_k) \end{bmatrix}$
2. $\mathbf{x}^{(1)} = \mathbf{x}_k + \frac{h}{2}\mathbf{k}_1$
3. $\mathbf{k}_2 = \mathbf{f}(\mathbf{x}^{(1)}, \tilde{u}_{k+1/2}) = \begin{bmatrix} \tilde{v}^{(1)} \\ \tilde{\alpha}_\theta(\tilde{y}^{(1)}, \tilde{v}^{(1)}, \tilde{u}_{k+1/2}) \end{bmatrix}$
4. $\mathbf{x}^{(2)} = \mathbf{x}_k + \frac{h}{2}\mathbf{k}_2$
5. $\mathbf{k}_3 = \mathbf{f}(\mathbf{x}^{(2)}, \tilde{u}_{k+1/2}) = \begin{bmatrix} \tilde{v}^{(2)} \\ \tilde{\alpha}_\theta(\tilde{y}^{(2)}, \tilde{v}^{(2)}, \tilde{u}_{k+1/2}) \end{bmatrix}$
6. $\mathbf{x}^{(3)} = \mathbf{x}_k + h\,\mathbf{k}_3$
7. $\mathbf{k}_4 = \mathbf{f}(\mathbf{x}^{(3)}, \tilde{u}_{k+1}) = \begin{bmatrix} \tilde{v}^{(3)} \\ \tilde{\alpha}_\theta(\tilde{y}^{(3)}, \tilde{v}^{(3)}, \tilde{u}_{k+1}) \end{bmatrix}$
8. $\mathbf{x}_{k+1} = \mathbf{x}_k + \frac{h}{6}(\mathbf{k}_1 + 2\mathbf{k}_2 + 2\mathbf{k}_3 + \mathbf{k}_4)$

Because this integration is implemented with standard PyTorch tensor operations, gradients flow directly back through the steps via automatic differentiation.

### 5. Training Strategy (Short-Trajectory Rollouts)

- **Windowing:** Full-sequence BPTT across 3072 steps is prone to exploding gradients and slow CPU computation. Instead, train on overlapping short trajectories of length $L \approx 20$ to $30$ steps.
- **Batching:** Randomly sample mini-batches (e.g., batch size 32 or 64) of trajectory windows from the training set.
- **Trajectory Initial State:** For each window starting at index $j$, initialize with:
  - $\tilde{y}_0 = \tilde{y}_{\text{train}}[j]$
  - $\tilde{v}_0 = \frac{\tilde{y}_{\text{train}}[j+1] - \tilde{y}_{\text{train}}[j]}{h}$
- **Loss Function:** Mean Squared Error over the predicted position trajectory against measured position:
  $$\mathcal{L} = \frac{1}{B \cdot L} \sum_{b=1}^B \sum_{k=1}^L (\tilde{y}_{b, k}^{\text{pred}} - \tilde{y}_{b, k}^{\text{true}})^2$$
- **Optimization:** Adam optimizer with initial learning rate $\eta = 10^{-3}$, cosine annealing or step decay.
- **Budget Control:** Track elapsed time; run for up to ~60 epochs, cutting off training when elapsed time exceeds 180 seconds (3 minutes) to guarantee execution comfortably under the 5-minute CPU constraint.

---

### 6. Free-Run Rollout Evaluation Protocol

- **Initial State:** 
  - $y_0 = y_{\text{excerpt}}[0]$, so $\tilde{y}_0 = y_0 / Y_S$.
  - Initial velocity estimated by forward difference: $v_0 = \frac{y_{\text{excerpt}}[1] - y_{\text{excerpt}}[0]}{\Delta t}$, so $\tilde{v}_0 = v_0 / V_S$.
- **Simulation:** Integrate RK4 sequentially over the **entire excerpt** of 4096 steps ($N_{\text{train}} = 3072$, $N_{\text{test}} = 1024$) without re-injecting any ground-truth $y$ or $v$ measurements. Only the measured input signal $\tilde{u}_k$ is fed into the integrator.
- **Dimensional Reconstruction:** Convert the predicted trajectory back to volts:
  $$y^{\text{pred}}_k = \tilde{y}^{\text{pred}}_k \cdot Y_S$$
- **Metrics:**
  Compute Root Mean Square Error on volts:
  $$\text{RMSE}_{\text{train}} = \sqrt{\frac{1}{3072}\sum_{k=0}^{3071}(y_k^{\text{pred}} - y_k)^2}$$
  $$\text{RMSE}_{\text{test}} = \sqrt{\frac{1}{1024}\sum_{k=3072}^{4095}(y_k^{\text{pred}} - y_k)^2}$$
